# TP02-Web

TP02 프로토타입의 WebGL 플레이 빌드. 모바일 브라우저에서 조작감을 확인하려고 둔다.
소스는 별도 비공개 저장소에 있고, 여기에는 빌드 산출물만 올린다.

플레이: https://lla830126.github.io/TP02-Web/

## 조작

화면 어디든 손가락이 닿은 지점이 원점이 된다.

- **좌우 드래그** — 이동. 민 거리에 비례해 속도가 붙는다
- **위로 튕기기** — 그 방향으로 점프. 최근 0.12초 안에 위로 55px 이상,
  수평에서 28도 이상이어야 한다. 걷는 중 손가락이 서서히 위로 흐르는 것은
  점프로 치지 않는다
- **사다리에서 세로 드래그** — 오르내리기. 사다리 위에서는 점프 판정을 잠근다
- **우측 액션 버튼** — 상황에 따라 `채집` 또는 `내리기`. 자리는 항상 고정이다

오브젝트 위의 노란 아이콘은 알림 전용이다. 실행은 액션 버튼이 맡는다.

## 배포

```bash
./deploy.sh [빌드경로] [커밋메시지]
```

Unity 에서 `Build/WebGL` 로 빌드한 뒤 실행하면 복사·캐시무력화·푸시·반영확인까지
하고 플레이 링크를 출력한다.

스크립트가 막아주는 것들:

- **빌드가 소스보다 오래됐으면 중단** — Unity 빌드가 끝나기 전에 배포해
  옛 빌드를 올리는 사고를 막는다
- **산출물 네 개가 다 있고 크기가 안정될 때까지 대기** — 쓰는 중에 복사하면
  반쪽짜리가 올라간다
- **100MB 넘는 파일 거부** — GitHub 상한. 개발 빌드는 압축이 안 걸려 wasm 이
  100MB 를 넘는다
- **에셋 URL 에 내용 해시 태그** — 파일명이 매 빌드 같아서, 이게 없으면
  브라우저 캐시(max-age=600)와 Unity IndexedDB 캐시가 옛 빌드를 계속 물고 있다
